# Рекомендательные системы для музыкальных треков

Это проект, который развился из практической работы по машинному обучению, которую я выполнял в университете. Задача была построить рекомендации музыки по истории прослушиваний, то есть для каждого пользователя подобрать новые треки с учетом его предпочтений.

В учебной части я реализовал на Python несколько основных компонентов рекомендательной системы. Для User2User использовал коллаборативную фильтрацию - определял похожих пользователей с помощью коэффициента Жаккара и на основе их прослушиваний рассчитывал оценки для других треков. Второй подход - ALS, матричная факторизация, в которой пользователи и треки представляются скрытыми факторами, а их значения последовательно уточняются при обучении. Для оценки качества ранжирования реализовал AP@K и MAP@K.

Позже я собрал решение в один Python-файл и расширил его до небольшого воспроизводимого эксперимента. Добавил два простых ориентира для сравнения - случайные рекомендации и рекомендации популярных треков. Кроме исходного ALS, включил Implicit ALS, который лучше учитывает специфику данных о прослушиваниях, когда известен факт взаимодействия, но нет явной оценки песни. В итоге сравниваются пять моделей.

Оригинальный набор данных у меня не сохранился, поэтому для эксперимента использовал синтетическую историю прослушиваний с заданными музыкальными предпочтениями. В ней 160 пользователей, 180 треков и 3840 взаимодействий. Для каждого пользователя 20 прослушиваний попали в обучающую выборку и 4 - в тестовую. Модели рекомендуют только те треки, которых пользователь не слушал в обучающей выборке.

Качество сравнивал по MAP@10, HitRate@10 и Coverage@10. Первые две метрики помогают оценить, насколько хорошо модели находят релевантные треки, а последняя показывает, какая доля каталога вообще попала в рекомендации.

| Модель | MAP@10 | HitRate@10 | Coverage@10 |
|---|---:|---:|---:|
| User2User (Jaccard) | 0.1009 | 0.6438 | 0.5056 |
| Implicit ALS | 0.0771 | 0.5312 | 0.9722 |
| ALS по наблюдаемым взаимодействиям | 0.0406 | 0.3438 | 0.1056 |
| Популярные треки | 0.0404 | 0.3438 | 0.1000 |
| Случайные рекомендации | 0.0153 | 0.1875 | 1.0000 |

На этом наборе данных лучшим по MAP@10 оказался User2User. При этом Implicit ALS охватил заметно больше треков.

## О запуске
Для работы нужны библиотеки NumPy и Pandas. При запуске скрипт сам создает данные, обучает модели и сохраняет результаты в папку `recsys_results`.
